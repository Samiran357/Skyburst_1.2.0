# Skyburst

A fireworks sky that runs in your browser. Tap or drag to launch shells over a night harbour with a skyline, moon and water reflections.

**Live demo:** https://YOUR-USERNAME.github.io/fireworks/

## Features

- 10 burst shapes: Peony, Ring, Heart, Star, Willow, Crackle, Palm, Spiral, Double, and Auto
- 7 color palettes, including a rainbow Prism palette
- Rockets with glowing trails, sky flashes on every burst, and reflections in the water
- Synthesized sound: launch whoosh, boom and crackle (no audio files)
- Auto show mode, slow motion and a one-button finale
- Works on phones, tablets and desktop

## How to use

| Action | What it does |
| --- | --- |
| Tap the sky | Launch one shell |
| Drag across the sky | Paint a salvo |
| `Space` | Fire the finale |
| `1` to `0` | Pick a burst shape |
| `M` | Mute or unmute |
| `H` | Hide or show the controls |

## Run it locally

No install or build step. Download `index.html` and open it in any modern browser.

## Built with

Plain HTML, CSS and JavaScript. Fireworks are drawn on an HTML canvas and sound comes from the Web Audio API. Fonts (Unbounded and JetBrains Mono) load from Google Fonts.
